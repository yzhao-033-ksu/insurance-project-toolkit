# [Insurance Claims Analysis Toolkit]

**Question:** How do claim amounts vary across different age groups, and which age group has the highest average claim amount?

**Track:** Actuarial math

## Data

- **Source:** Synthetic insurance claims data generated by the team for educational purposes.
- **License:** Original synthetic data created by the team; no third-party license applies.
- The full dataset goes in `data/raw/` (not committed). A small sample is in `data/sample/`.

## Install

```bash
git clone https://github.com/yzhao-033-ksu/insurance-project-toolkit.git
cd insurance-project-toolkit
pip install -r requirements.txt
```

## Run

```bash
pytest -q
```
